# Stein 等人 2002
**閱讀紀錄**：全文文字層已讀（12 頁 PDF，期刊頁 58–69）；式子在文字層被拆成單字元，式(3)–(14) 的符號依上下文與作者敘述判讀，未裁切公式圖。未開任何圖檔（本檔引用的 Fig. 1、2 只從圖說與正文讀其文字敘述）。
**閱讀範圍**：引言（p.58–59）、GLRT 與異常偵測演算法（p.59–62）、局部常態／混合模型（p.62 起）、偵測表現（p.65）、結論（p.67）。聯合決策、Chronochrome 變化偵測僅略讀。
**論文群中的角色**：Benmoussat 等人 2012 的 Sec III-B 幾乎照 Stein 等人的措辭定義異常偵測（背景模型取自測試像素的局部鄰域或影像中的大範圍區域），式(3) 的 RX 與「具 CFAR 性質」也引自此文（Benmoussat 的參考文獻 [6]）。本文解釋 Sec III-B 的「局部／全域背景」兩種定義，以及式(3) 為何可視為 GLRT 的結果。

## 困難點與研究動機
- 已知目標光譜的偵測器會因輻射量與反射率轉換、大氣補償誤差而產生訊號失配損失（p.58–59）。
- 目標光譜種類多、不確定，因此發展不需目標光譜、只對照背景模型的異常偵測器（p.59）。

## 核心想法與方法
- 異常是相對於背景模型而定義；背景模型以測試像素的局部鄰域，或影像的大範圍區域，用適應方式估計（p.59）。
- 三種背景模型：局部常態、全域常態混合、全域線性混合（p.59）。
- RX 由 GLRT 導出（Kelly [14]、Reed and Yu [15]），假設目標光譜與背景共變異皆未知；有限樣本形式為式(3)，N→∞ 時收斂為式(4)：(x−μ̂)ᵀ Γ̂⁻¹ (x−μ̂)，Γ̂ 為參考資料的樣本共變異（p.60）。
- 式(4) 與常態分布下的 −log 機率單調相關，可視為多變量能量偵測器（p.60）。

## 論證脈絡
先說明目標比對的缺點 → 以背景模型定義異常 → 局部與全域各有利弊 → 以 GLRT 導出 RX → 指出局部常態模型對實際資料不一定成立 → 提出混合模型與聯合決策。

## 證據
### 局部與全域異常各自的弱點（p.59）
- 標籤：原論文報告
- 如何檢驗：以情境舉例（草原上的孤立樹木），無量化實驗。
- 結果：局部偵測器易對孤立的光譜異常產生誤報，即使影像別處有成片的樹；全域偵測器不會有這類誤報，但若孤立目標光譜與已歸類的背景相似則偵測不到。
- 可以支持什麼：Benmoussat 等人選全域共變異（Sec V）時，缺陷光譜若接近大片背景就可能漏掉。

### RX 的 CFAR 性質（式(5)、(6)，p.60）
- 標籤：原論文報告
- 如何檢驗：漸近分布推導。
- 結果：N→∞ 時，H0 下 RX → δ·χ²_K（δ=1 實數、2 複數），分布與未知參數無關，故有 CFAR；H1 下為非中心 χ²。
- 可以支持什麼：Benmoussat 等人 Sec III-B「RX 具 CFAR」的出處；門檻可依誤警率設定。

### 局部常態模型不一定成立（p.62）
- 標籤：原論文報告
- 如何檢驗：BHEP 檢定，錯誤拒絕機率 10⁻⁵。
- 結果：一景高光譜影像中超過 90% 的像素拒絕局部常態假設。
- 可以支持什麼：解釋 Benmoussat 等人 Sec V「背景不均勻時 RX 不理想」的一個原因（背景含多種材料時不是單一高斯）。

### 實例比較（p.65）
- 標籤：原論文報告
- 如何檢驗：同一張高光譜影像，固定 Pd 比較誤警數。
- 結果：該例中 GMRX 誤警比 RX 多，NFINDR-STD 比 RX 少，聯合決策 MAF 最少；偵測目標數排序 RX < GMRX < NFINDR-STD < MAF。
- 可以支持什麼：局部 RX 不是最佳，但結論來自單一影像。

## 解決的部分與剩餘問題
**作者明列的局限**：局部常態模型可能不適用於小區域含多種材料的情形（p.62）；維度越高需要越高 SNR（p.67）；未來需要保持目標 SNR 的降維。
**我的判讀**：
- 待驗證的推論：Benmoussat 等人用整個偽光譜立方體估共變異，屬 Stein 等人所說的「全域」背景；其 PSC 只有 3–60 個元件且為人造光照維度，Stein 的維度與 SNR 討論（K 越大 Pd 越差）可能適用，但本文針對遙測資料，未驗證能否搬到金屬表面。
- 本文把「局部 RX」稱為 Reed–Xiaoli，而 Chang 與 Chiang 2002 描述的 RXD 用全域平均與共變異；兩篇對 RX 的預設背景範圍不同，閱讀時要分清楚。
